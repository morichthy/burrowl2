# 检索与阅读

先读同目录上一级的 RULES.md（公共规则）。

> 查询时顺手维护阅读会话笔记（`reading_note`：目的、认知、handoff），见 [RULES](../RULES.md) 第 8 节。

## 选择检索方式

| 需要 | 工具 |
|---|---|
| 按主题查找 | `search(query, mode="reuse")` |
| 探索新路线，避免被已有结论锚定 | `search(query, mode="explore")`：不返回框架页，默认也不返回过程内容 |
| 设备编号、错误码、函数名、原句等**逐字**查找 | `search_exact(text)`：不分词、不排序，列出含有这段文字的段落 |
| 检索命中之外、顺着关系连着的条目（类比、相关判断、同一对象） | `search_associate(query=… 或 seeds=[…], hops=1)`：结果不是检索命中，见下文 |
| 某个对象的全部历史 | `timeline(object)` |
| 看过程日志 | `search(..., include_log=true)` 或 `session_events` |
| 一个对象的全部条目，按约束、有争议的结论、类型分好组 | `object_view(object)` |
| 原件有哪些页、哪些已抽取、可信度档 | `artifact_layer(artifact_id)` |
| 连已退役的原件也要找（默认不返回） | `search(..., include_retired=true)`：已退役的排在最后 |
| 只看本地实证（或只看外部报告、推断） | `search(..., source="local")`：只返回依据全部为本地实证的判断、本地实证原件和规定；`external` / `inferred` 返回依据含该来源的。`search_exact`、`search_associate` 同样可用 |

## 检索策略

1. **怎样写查询**：关键词和自然语言都可以，命中一部分词也能召回。重要的术语、型号原样写进去。
2. **语言**：原件可能是英文或中文。中文查不到、或领域文献多是英文时，**再用英文术语查一次**（反过来也一样）。向量通道能做一部分跨语言匹配，但不保证；`channels.dense` 不是 `ready` 时完全没有跨语言能力。
3. **查不到或不够**：先看 `hints`。换一种说法、拆成更短的关键词、去掉限定条件，再查一次（二轮）。仍然没有，就如实写"没有找到"，不要编造。
4. **名次只表示相关度**：排在前面不等于可信。每条的 `status_note` 写明它是原件、判断还是框架，依据来源，是否被替代、有反对、依据不完整。相关的有效约束单独列在最前的 `constraints` 里，必须遵守。
5. **用好结果里的线索**：
   - `passages`：命中的检索单元（最多几个见结果的 `params.passages_shown`，人在设置里调整，默认 3）。`cite_as` 是其中最相关的段落，`read_as` 是这个单元覆盖的段落范围，可以直接交给 `artifact_read(locator=read_as)`。
   - `more_matches`：同一条目还有几处命中没有展示。条目可能还有更多相关内容时，用 `search_exact` 找具体文字，或按 `size` 判断是否值得读更大的范围。
   - `basis`：判断与框架页的依据（原件段落、判断），带一句片段。**框架页不能作为依据**，要依据就去读它的 basis。
   - `relations`：一跳关系。`cited_by` 是引用这份原件的判断（解读），`links` 是判断之间的关系，`in_pages` 是用到它的框架页。探索模式下不给框架页和解读。
   - `read_before`：本会话已经读过其中的段落。
   - `params`：本次用的检索参数（返回条数、每条展示几个命中单元、片段长度等）。结果数量或片段长度不够时，按 `params` 判断要不要加大 `limit`、改用 `search_exact` 或直接读原件；不要假定固定的数字。
6. **联想**（`search_associate`）：要找类比、相关前提、同一对象的其他记录，或检索找不全时使用；不是默认检索。结果顺着已有关系（判断关系、引用、输入清单、实体提及、共享对象、向量近邻）找到，每条带路径 `via`，标为"联想，非检索命中"。相关与否必须读原文判断；探索模式下只走判断层关系、引用、共享对象和向量近邻。
7. **预算**：先看片段和线索，再决定读哪一段；不要一上来就读整份长原件。

## 读结果

- 每条结果带坐标（只写例外，正常值省略），按"地位 → 类型 → 现状 → 说明"读：
  - 地位：`layer`（原件、判断或框架）× `sources`（`local` 本地实证、`external:peer_reviewed` 等外部报告、`inferred` 推断），只由这一版自己的依据决定；
  - 类型：`kind`（原件类、结论 / 过程 / 规定、框架页类型）；
  - 现状：`state.validity`（当前有效之外才写：被替代、已撤回、已退役、依据失效）、`state.review`、`state.marks`（被佐证、被反驳、依据有变化……，带处数）；
  - 说明：`notes.author`、`notes.quoted`（原作者）、`notes.marks`（依据含未确认的识别、转述但没写条件、**适用范围未明**……）。写"适用范围未明"的判断，写它的人声明了适用范围尚不清晰：看它的 `conditions`（哪些条件清楚、哪些不清楚），当作线索，不要直接套用。
  标记的完整出处（哪条关系、哪一端）用 `entry_get` 看。
- 判断正文里的 `[^1]` 是行内引用，编号对应这一版某几条关系（`entry_get` 的关系里 `qualifiers.marker`）；关系可能带 `why`（为什么连这一条）和 `role`（作用，如定义、方法、数据、条件）。要核对一个量的定义或条件的出处，先看带 `role` 为"定义"或"条件"的关系，再读它指向的原文段落。
- 每条结果带全部关系 `links`（出边 `out`、入边 `in`，每条 `{p 谓词, ref}`）：依据了谁、被谁依据、被谁佐证或反驳，顺着继续找；超过上限时写明剩余条数，用 `entry_get(ref, links=谓词, offset=…)` 取全。
- 命中旧版文字时，结果主体仍是当前版，`old_hits` 列出命中的旧版（版本、段落、被哪一版替代、改动理由）；旧说法可能正是你要找的，需要时用 `entry_get(jdg_…@2)` 读那一版。
- 默认按相关度排序（`order="standing"` 时按"依据来源 → 综合程度 → 复核"逐级排）；两种都**不是**可信度打分。
- 最前面的 `constraints` 是有效的约束、决定和指令，必须遵守。
- `status_note` 写"转述 · 原作者 …"的是从外部材料转述的结论（坐标 `notes.quoted`）；写"转述但没写条件"的，原文没给全条件，用前对照自己的条件。按 RULES 第 4 节决定信几分、要不要回原文、要不要本地验证。筛选：`source`（依据来源）、`kinds`（类型）、`quoted=true`（只看转述的）。
- 框架页的结果带 `basis_mix`：这一页的依据里有几条本地实证、外部报告、推断，其中几条结论只有外部依据。`note` 一句话说明；只有外部依据的重要结论，用前回原文核对。
- 现状为"被替代"的条目，用 `entry_get` 看是新版本还是被别的条目替代、为什么。
- 现状为"已退役"的原件已由人退役；`entry_get` 的版本历史里 `replaced_by` 是替代它的原件，依据请改用它。

## 展开与阅读

- `entry_expand(id)` 给出背景：
  1. 来源（原件：出处、作者、保存方式、原位置）或条件（过程日志、事实记录：条件、方法、边界、缺口）；
  2. 同一来源的前后内容；
  3. 涉及的对象（名称和条数；要看对象的全部条目用 `object_view`）；
  4. 依据或评价了它的判断（这是解读，不是原件内容）。
- 检索命中原件时，结果带 `cite_as`（原件段落，如 `art_…#p3-2`；写入关系时系统补上版本号）、`read_as`（段落范围，如 `p3-8:p3-12`）、所在单元和可信度档。
- 候选不等于已读。要依据原件下结论，必须用 `artifact_read` 读过，并在 `cites` 里写原件段落。
- 图片、扫描页没有文字时，`artifact_read` 会报 `UNREADABLE` 并说明怎么做：用 `artifact_view` 看图。
- Word / PPT 的公式块（`formula`，`latex_source.method = omml`）和段落里的行内公式（`inline_math`）的 LaTeX 取自原件的公式结构，可以直接读，不必看图核对。
- 读到 PDF 的公式块（`formula`）时，抽出的字符不可靠：有 LaTeX 补充时读它（标了来源与是否确认），没有时用 `artifact_view(artifact_id, anchor=…)` 看公式裁切图再理解。Excel 原件按工作表（`s1`、`s2`…）分单元，表格块的锚点如 `s2-1`，块里带单元格范围。
- 框架页（综合页、实体页）只能帮你找方向，不能作为依据。写判断时引用它背后的原件或判断。
