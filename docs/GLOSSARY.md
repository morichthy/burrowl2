# 术语表

每个术语只在这里给出权威的短定义：它是什么、不是什么、代码中的标识。其他文档首次出现时链接这里。

## 模型

| 术语 | 定义 | 不是什么 | 代码标识 |
|---|---|---|---|
| 三列 / 综合程度 | 内容按综合程度分成原件、判断、框架三列 | 不是可信度等级 | `layer`：`original` / `judgment` / `framework` |
| 原件 | 原文如实的内容：登记的文件或文本、过程日志、事实记录 | 不是"关于世界的事实"；原件里的内容只能以"某来源说了 X"引用 | `art_` / `evt_` / `rec_` |
| 判断 | 当时谁、依据什么、认为了什么。只追加，不复核、不裁决，冲突可以并存 | 不是"现在该信的结论"（那由框架回答） | `jdg_`，表 `judgments` |
| 框架 | 实体、实体页、概念页、综合页、描述页、关系图的边、索引。可以再生 | **永远不能作为依据** | `ent_` / `pg_` / `edg_` |
| 依据来源 | 依据从哪里来：本地实证、外部报告、推断。三类没有固定高低 | 不是作者身份 | `source_class`：`local` / `external` / `inferred` |
| 本地实证 | 在本项目内执行、测量或直接观察得到的依据（旧称"亲自执行"）。人写结论时可勾选；AI 的执行通过过程日志和事实记录留痕 | 不是"可信"的同义词 | `local`；`local_observation` |
| 推断 | 由推理、讨论或 AI 生成、没有直接观测的依据（旧称"推断或讨论"） | — | `inferred` |
| 外部报告细分 | 外部报告的类型：同行评议、预印本、厂商资料、网页 | — | `external_tier` |
| 写入时可信度 | 写入判断时由系统根据依据推出、之后不变的部分：来源类型、是否全部为本地实证、依据是否完整 | 不由 AI 填写；不是"当前可信度" | `judgments.data.credibility` |
| 全部依据为本地实证 | 全部依据都是本地实证（旧称"我们验证过的"） | 混合了文献的不算 | `all_local` |
| 结论 | 关于对象的陈述，可以作为依据 | — | `conclusion` |
| 过程 | 提问、尝试、停下的路线（可带重开条件）、目的。是重新综合框架的依据；不能作为结论的依据；探索模式默认不返回 | 不是证据 | `process`；`reopen_condition` |
| 规定 | 约束、决定、指令：规定该怎么做，不陈述世界怎样，不参与真假排序 | — | `normative` |
| 系统记录 | 复核、更正、撤回、原件缺陷：由人在工作台操作时生成，不能直接选择 | — | `SYSTEM_KINDS` |
| 判断类型 | 写的人在结论、过程、规定三种中选择（AI 在 `judgment_write` 中填写，人在工作台选择）；另有系统记录。旧称"言语类型"（D-14 前有 12 种） | 不是系统推断出来的 | `judgments.kind`；`WRITABLE_KINDS` |
| 当前主张状态 | 某条判断是否已被替代、更正、撤回，有没有反对；由关系实时计算 | 不写回判断 | `JudgmentService.status` |
| 读取记录 | 读了哪份原件、哪个版本、哪一段，以及读到的原文；自动日志，不作为条目显示，在原件页的段落旁查看（设计稿 01 D-03） | 不是摘要；不是判断的必经依据 | `rd_`，表 `reads` |
| 抽取层 | 原件的可读文字，按单元（PDF/PPT 的页、Word 正文、图片、音视频）组织，带版式块和可信度档；索引、工作台显示、读取、引用都来自它（设计稿 01 D-10） | 不是另一份原件；原件字节始终原样 | 表 `extractions`，`ex_` |
| 可信度档 | 抽取文字的来源：原样复制 > 解析文字层 > 人工转写 > OCR 识别 > AI 识别；可由人确认 | 不是判断的可信度 | `copy` / `parsed` / `manual` / `ocr` / `ai` |
| 原件段落 | 引用原件内容的写法 `art_…#段落`：`seg-N`（文本、Word）、`p3-2`（第 3 页第 2 段）、`img-1`、`av-4`；写入判断时记下段落指纹 | 不是读取记录 | `cited_segments` |
| 对象 | 条目讲的是什么东西：实体（`ent_…`）或规范化的叫法；一条可以有多个；用于对象页、约束检查、建页门槛 | 不是标签分类 | 表 `entry_objects` |
| 页面快照 | 用本机 Office / LibreOffice 把 PPT、Word 转成的 PDF，只用于在工作台按原样显示 | 不进索引，不能引用 | 抽取记录 `snapshot` |
| 事实记录 | 从过程日志或原件片段升级而来的正式条目：对象、条件、方法、结果（逐字）、边界、缺口 | 条件不能事后补写 | `rec_`，表 `records` |
| 边界 | 事实记录是否完整：完整、截断、只读了一部分、受权限限制 | — | `boundary` |
| 过程日志 | 只追加的操作与输出记录，默认不进入检索 | — | `evt_`，表 `events` |
| 输入清单 | 框架条目生成时依据的不可变单元及其版本 | — | 表 `derivation_inputs` |
| 时效 | 框架条目的输入是否变化：有效、输入已变化、被替代、未核查。只降不升 | 不是复核状态 | `freshness` |
| 复核状态 | 框架条目是否经人复核：AI 生成未复核、人已复核、被驳回、按规则 | 不改变判断层的内容 | `review` |
| 传播 | 依据变化后，把下游框架条目标为"输入已变化" | 不修改判断 | `Propagation.propagate` |
| 术语连接 | 把一个叫法连到实体，分确定、较有把握、拿不准三档 | 不按 AI 自报的把握分档 | `LinkingService.link_term` |
| 别名表 | 人决定过的"叫法 → 实体"对应 | AI 不能直接写入 | 表 `aliases` |
| 地位坐标 | 一条结果的列、依据来源、外部细分、是否混合、依据是否完整、复核、时效、是否被替代 | 不是一个分数 | `RetrievalService.coordinates` |
| 复用模式 / 探索模式 | 检索时三列都返回 / 不返回框架、展开时不给解读 | — | `search(mode=…)` |
| 待决策 | 等人处理的事项：术语连接、待复核、需重新综合、操作前未检查约束、传播超限 | 不阻塞写入 | 表 `decisions` |

## 程序与运行

| 术语 | 定义 | 代码标识 |
|---|---|---|
| 账本 | 原件一列与判断一列的存储，只追加，唯一不可替代 | `ledger.sqlite`、`blobs/` |
| 操作 | 一个带类型注解的函数，同时生成命令行、HTTP 和 MCP 三个入口 | `@op`，`interfaces/ops.py` |
| effect | 操作的开放范围：read / write 三个入口都开放；user 只给人；admin 是维护类 | `OpSpec.effect` |
| 调用者身份 | 由入口决定的作者：人、AI、系统；加上会话 | `Actor`，`interfaces/runtime.py` |
| agent 运行 | 工作台启动的一次本机 agent CLI 进程，有独立的身份与会话 | `run_`，表 `agent_runs` |
| 数据目录 | 一个工作区的全部数据 | `Workspace.root` |
| 安装根目录 | `versions/`、`current`、`bin/` 所在的位置 | `BURROWL_ROOT`、`install_root()` |
| 旧版 | burrowl 0.x（A_work_auto_flow_plus），2026-11-05 退役 | `import_v1` |
